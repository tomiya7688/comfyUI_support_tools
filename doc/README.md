## 日本語

### 言語方針

プロジェクト所有の README と文書は、日本語・英語の両方を維持します。

- 新規文書は日英両方を同時に作成する。
- 既存文書を実質的に変更する場合は、対応する他言語版も同じPRで更新する。
- 片方だけ先に変更して長期間不一致の状態にしない。
- 日本語版と英語版で仕様上の意味を変えない。
- ファイルを分ける場合は、相互リンクを文書冒頭へ置く。
- 自動生成物、第三者が提供した原文、ライセンス原文など、翻訳によって正本性を損なうものは例外とする。その場合でも必要に応じて説明用の日英文書を別途用意する。

### 既存文書の移行

既存文書には片言語のみのものがあります。これらは削除や一括機械翻訳ではなく、内容を確認しながら順次ペア化します。
未対応文書を実質的に変更するPRでは、その文書の日英対応も同じPRの作業範囲に含めます。

## English

### Language policy

Project-owned README files and documentation are maintained in both Japanese and English.

- Create both Japanese and English versions for new documentation.
- When an existing document is substantively changed, update its paired language version in the same PR.
- Do not leave one language materially ahead of the other for an extended period.
- Japanese and English versions must express the same specification and requirements.
- When separate files are used, place reciprocal language links at the top of each document.
- Machine-generated artifacts, third-party original text, and canonical legal/license text are exceptions where translation could damage source fidelity. Provide bilingual explanatory documentation separately when useful.

### Legacy migration

Some existing documents currently exist in only one language. They will be paired progressively after content review rather than being replaced by unchecked bulk machine translation.
When a legacy unpaired document is substantively changed, adding/updating its Japanese-English pair is part of the same PR.
