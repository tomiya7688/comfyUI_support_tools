# Development workflow

1. Fetch the remote before deciding the next action. If it fails, report the unverified freshness and stop any decision that requires current remote state.
2. Read [AGENTS.md](../../../AGENTS.md) and the [Japanese workflow](../../../doc/ワークフロー/ワークフロー.md) or [English workflow](../../../doc/ワークフロー/workflow.md).
3. Inspect relevant open PRs first, then select one Issue or the existing PR. Work only within its scope.
4. Load only the design, implementation, or review section needed for your assigned role. Use the handoff fields in the workflow; record shared duties separately from role-specific duties.

The linked workflow is canonical. Do not duplicate or relax its safety gates here.
