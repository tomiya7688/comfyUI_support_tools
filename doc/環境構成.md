# Tabbed Tools 環境構成

`run.bat` は `K:\sd\.venv` の Python 3.10 で GUI 本体を起動する。初回起動時は
`setup_kadoka_tools.bat` がこの環境を作成し、`requirements-kadoka-tools.txt` を検証する。

GUI本体は標準ライブラリだけを使う。重い機能の依存関係は混在させず、実行時に各機能の
既存環境を明示的に利用する。

| 機能 | 実行環境 |
| --- | --- |
| Tabbed Tools GUI | `K:\sd\.venv` |
| WebUI1111 | `stable-diffusion-webui\venv` |
| ComfyUI | `paths.json` で設定した ComfyUI 環境 |
| Touka（OpenCV） | `nuno\_touka\.venv` |

他PCでは、先に WebUI1111 / ComfyUI / Touka をそれぞれの手順で用意し、
`user_data/input/config/common/paths.json` のパスを設定する。その後 `run.bat` を実行する。
