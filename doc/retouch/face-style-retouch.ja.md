# Face Style Retouch

顔だけの線・塗り・画材・時代感・描き込み密度を変える共有契約と処理パイプラインを追加しました。本人性、表情、顔向き、視線、髪、色調、編集マスク外の画素を個別に評価・保護でき、main / selected / group / all の顔選択、前髪保護、複数backend候補を扱います。顔検出や評価器がない場合は成功扱いにせず、レビューへ戻します。

顔パーサー、本人性・表情評価モデル、生成編集モデルの重みは同梱していません。ホスト側から `FaceRegionProvider`、`FaceStyleBackend`、`FaceStyleEvaluator` を注入できます。現時点でメインGUIに編集backendは構成されておらず、このAPIから実画像の編集を実行するにはホスト統合が必要です。参照画像の人物identityを使わず画風特徴だけを扱う契約とし、評価器なしに本人性保持を主張しません。Semantic Eraseとは独立した処理で、表情変更は対応する専用機能と明示的に連結します。
