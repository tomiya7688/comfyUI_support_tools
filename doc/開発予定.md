# nuno
画像データセットから名前付きToukaプリセットを作成可能。対応画像を検査し、強調対象参考画像と選択した強調対象を保存する。残作業: 複数データセットの形状クラスタリングと学習済み特徴量による自動命名提案。

## 半透明素材越し強調用AIモデル　優先度: 2

Fashionpediaの通常衣類画像と注釈ポリゴンを元に、半透明の布・Tシャツ・薄紙・フィルムを合成した学習ペアを生成する。入力は半透明素材越しの画像、正解は元の衣類分類マスクとし、見えている弱い輪郭・色差から対象の形状確率を推定できるようにする。

1. Fashionpediaの46分類マスクを読み込み、透過対象の色・模様・透過率・陰影を重ねた学習データを生成する。
2. CUDA対応の軽量セグメンテーションモデル（DeepLabV3 MobileNetV3）をTouka専用venvで学習する。GTX 1080 8GBを前提に、初期値は384px・batch size 1とする。
3. 学習済みモデルとラベル定義、学習設定、評価結果を `user_data/input/models/touka` に保存する。
4. Toukaの強調対象（服、シャツ、ブラジャー、ショーツ・パンツ、リボン等）ごとに確率マスクを取り出し、既存の色差・ROI・動画追跡と融合する。
5. 動画では場面転換時に再推定し、前後フレームの追跡でマスクを安定化する。確信度が低い部分は補完せず、診断結果へ記録する。
6. 元画像のみ、合成透過画像、実動画の3種類でマスク・確信度・時間安定性を評価する。完全に視覚情報がない裏側を生成・断定する機能にはしない。

完了条件: 合成データ生成、学習、モデル選択、画像・動画推論、確信度/マスク出力、学習前後比較を実装し、少数サンプルで学習・推論の動作を検証する。

# nunoの精度せんたくについて
Lv1 light RGBや彩度、コントラストをいじって強調する程度(もちろん処理自体の評価は行われるため最適結果が表示される) 明るめに補正する
Lv1 dark RGBや彩度、コントラストをいじって強調する程度(もちろん処理自体の評価は行われるため最適結果が表示される) 暗めに補正する
Lv1 multi Lv1の二種類を実行する　出力は2つになる
Lv2 Lv1の部分は良い方を採用する 動画の複数フレームからの推定や評価関数などを利用
Lv3 normal Lv1,Lv2のやり方をもちろん適応しつつさらにAIを活用した高度な強調透過処理 
Lv3 smooth 元画像に対して透過部分と強調部分だけを戻してマージしつつ少し自然な形にする
Lv3 strong 元画像に対して透過部分と強調部分だけを戻してマージし、自然さよりも透過性を重視する
Lv3 multi Lv3の三種類を実行する、出力は1ファイルに対して3つになる
